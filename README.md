# 🚀 LeadGen Platform - Premium B2B Lead Generation

[English] | [Español abajo]

**LeadGen** is a powerful desktop application designed for B2B sales teams and marketing agencies. It automates the process of finding and qualifying leads directly from Google Maps and other sources, providing real-time data to boost your sales pipeline.

### ✨ Key Features
- **Smart Scraper:** Extract business data (Name, Phone, Website, Rating) with human-like behavior to avoid blocks.
- **Lead Management:** Integrated CRM to track opportunities and contact status.
- **Cloud Sync:** Securely sync your data across devices using Firebase.
- **Premium Analytics:** Identify businesses without websites or low ratings to offer your services.

# 🚀 LeadGen Platform - Generación de Leads B2B Premium

**LeadGen** es una potente aplicación de escritorio diseñada para equipos de ventas B2B y agencias de marketing. Automatiza el proceso de búsqueda y calificación de clientes potenciales directamente desde Google Maps, proporcionando datos en tiempo real para acelerar tus ventas.

### ✨ Características Principales
- **Scraper Inteligente:** Extrae datos (Nombre, Teléfono, Web, Valoración) simulando comportamiento humano para evitar bloqueos.
- **Gestión de Leads:** CRM integrado para rastrear oportunidades y estados de contacto.
- **Sincronización en la Nube:** Sincroniza tus datos de forma segura entre dispositivos.
- **Análisis Premium:** Identifica negocios sin sitio web o con bajas valoraciones para ofrecer tus servicios.
